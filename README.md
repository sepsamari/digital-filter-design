# Digital Filter Design with Python

This repository contains my practical exercises in digital filter design as part of my Master's studies in Smart Systems Engineering at Hanze University of Applied Sciences.

The goal is to understand FIR and IIR filters by designing them manually, implementing them in Python, and evaluating their performance.

## Topics Covered

- FIR filter design using zero placement
- FIR filters with multiple notch frequencies
- IIR filter design using poles and feedback
- Effect of pole radius on frequency response
- Low-pass filter design using repeated zeros
- FFT and frequency-response analysis
- Passband error and stopband attenuation
- Filter stability and group delay

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook

## Project Status

This is an ongoing learning project. More filter design exercises and comparisons will be added as I progress through the course.
